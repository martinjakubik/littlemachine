What kind of AI?

An image classifier.

You will teach it to answer one question:

"Is there a face in this image?"

You supply the examples. You do the training. The model is yours.

How does it work?

Four steps — and you'll do all of them:

  • Build a training set
  • Choose a learning architecture
  • Train the model
  • Test it on new images

Let's go.

Part 1 — The Training Set

An AI learns from examples, not from rules.

You never tell it what a face is.

You show it thousands of images and say: yes or no.

That collection of labelled examples is the training set.

Anatomy of an example

Each example is two things:

  • An input — a tiny 16-bit greyscale image
  • A label — face or not a face

Our dataset has 2,000 – 3,000 of these pairs.

Quality matters more than quantity: garbage in, garbage out.

The Dataset Editor

The editor lets you:

  • Load an existing dataset from disk
  • Browse examples and see their labels
  • Modify labels or remove bad examples
  • Add your own images and label them
  • Save the dataset back to your machine

A balanced dataset

If 90% of your examples are "not a face", the AI learns to always say "not a face" — and it will be right 90% of the time.

That's cheating. And useless.

Aim for roughly equal numbers of yes and no examples.

Try it: load a dataset, unbalance it on purpose, and see what happens.

Part 2 — Learning Architectures

Not all AIs think the same way.

The architecture is the shape of the machine — how inputs connect to outputs.

Different shapes work better for different problems.

Logistic Regression

The simplest possible classifier.

Each pixel gets a weight — how important is this pixel for the answer?

Add up all (pixel × weight). If the total is big enough: yes.

Works well when: the position of a feature matters more than its relationship to neighbours.

Fails when: what matters is how pixels relate to each other.

Neural Network

Multiple layers of weighted sums, with a twist between each layer.

Hidden layers let the network learn combinations of pixels — edges, curves, shapes.

Works well when: the answer depends on relationships between pixels, not just positions.

The cost: more parameters, longer training, harder to interpret.

Which one should you use?

Try both. The app lets you switch architectures and retrain.

  • For simple, position-based patterns → Logistic Regression
  • For anything involving shape or texture → Neural Network

Compare the accuracy numbers. Let the data decide.

Part 3 — Training

Training is a loop.

The model makes a guess → you tell it how wrong it was → it adjusts its weights slightly → repeat.

One pass through the entire dataset is called an epoch.

The loss function

How do you measure "how wrong"?

With a loss function — a single number that goes down as the model improves.

During training, watch the loss curve. If it's still falling, keep going. If it plateaus, you're done (or stuck).

How long does it take?

On this dataset, training takes about 20 minutes in the browser.

While it runs, you can:

  • Watch the loss curve update in real time
  • Peek at the model's weights — see them change
  • Read about what's happening under the hood

The model is working hard. So can you.

What the brain looks like

After a few epochs, visualise the weights.

For a logistic regression model, the weights are the same shape as the input image — you can literally see what the model "thinks" a face looks like.

For a neural network, the first layer's weights show the features it's learned to detect.

Part 4 — Accuracy

How do you know if the model is good?

You test it on examples it has never seen before.

This is the test set — held back from training on purpose.

What to measure

  • Accuracy — what fraction did it get right overall?
  • Precision — when it said "face", how often was it right?
  • Recall — how many real faces did it find?
  • Confusion matrix — the 2×2 table of all four possible outcomes

Tradeoffs

High precision, low recall: the model is cautious — says "face" rarely, but usually correctly.

Low precision, high recall: the model is generous — finds most faces, but cries wolf a lot.

Which is better? Depends on what you're using it for.

Try it: adjust the decision threshold and watch both numbers move.

Overfitting

If the model scores 99% on training data but 60% on test data, it has memorised the training set instead of learning from it.

This is called overfitting.

Signs: training loss keeps falling, test accuracy stops improving or gets worse.

Fix: more varied training data, fewer parameters, or stop earlier.

Part 5 — Run it!

Training is done. The model is saved on your machine.

Now: show it something new.

Load any image. The model will output a number between 0 and 1.

Above 0.5 → it thinks "face". Below 0.5 → it thinks "not a face".

You are the ground truth

At this point, only you know if the model is getting it right.

Try images that are:

  • Clear, straight-on faces — it should be confident
  • Faces at an angle or in shadow — does it still recognise them?
  • Things that look vaguely face-shaped — does it get fooled?

This is called qualitative evaluation. Numbers only tell half the story.

Save and share

Your trained model is a file — a list of numbers (the weights).

You can:

  • Save it and reload it later without retraining
  • Share it with someone else — they can run it instantly
  • Compare two models trained on different datasets

The model is yours. You made it.

What's next?

Everything you did here scales up.

  • More pixels → convolutional networks
  • More classes → softmax output
  • More data → transfer learning
  • More compute → GPUs, clusters, the cloud

The ideas are the same. The arithmetic is the same.

Only the scale changes.
